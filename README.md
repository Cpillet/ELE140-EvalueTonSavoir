# Questions GIFT pour ELE140 — ÉTS --- Utilisation de EvalueTonSavoir
 
Banque de questions au format [GIFT](https://docs.moodle.org/en/GIFT_format) destinées au cours **ELE140 — Circuits logiques** de l'École de technologie supérieure (ÉTS).

## Format GIFT
 
Le format GIFT (General Import Format Technology) est un format texte permettant de créer des questions pour Moodle. Les types de questions utilisés dans ce repo sont :
 
- **Réponse numérique** — pour les conversions de bases
- **Réponse courte** — pour les expressions booléennes et logiques
- **Choix multiple** — pour les questions théoriques (avec points partiels)
- **Vrai/Faux** — pour les questions de débordement

## EvalueTonSavoir

EvalueTonSavoir est un logiciel implémenté par les finissants de l'ÉTS introduisant de nouvelles features par rapport à des outils comme Wooclap ou Socrative.
